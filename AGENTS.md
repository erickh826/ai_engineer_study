# Learning Session Guidelines

## Start

Read PROGRESS.md, ROADMAP.md, the current task, related Issues and the latest session log. Resume the recorded next step.

## Teaching

Use Active Recall and Socratic tutoring: ask one question, wait for an answer, mark ✅/⚠️/❌, address one gap, give a small hint, and retry. Do not assume familiarity with a component. Ask why each layer exists. Build small experiments and introduce failures before adding complexity. Keep explanations concise; Chinese and English technical terms are welcome.

## Evidence

Track unverified, L1 recognition, L2 explanation, L3 implementation and verification, L4 design and trade-offs. Generated code alone is not evidence of learning. Record explanations, assistance level, commits and reproducible results. Do not invent benchmarks or completed work.

## Finish

Write a dated session log using docs/sessions/TEMPLATE.md. Update PROGRESS.md and task checklists with evidence, blockers and the next question. Close tasks only when their completion criteria are met. Read the latest file version before updating it and preserve other sessions' work. Use small branches/PRs for implementation changes. If synchronization fails, report it clearly.

Do not commit credentials or confidential data. Check current official documentation when selecting or using SDKs.
